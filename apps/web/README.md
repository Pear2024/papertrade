# Paper Crypto Coach Web

Next.js frontend for paper trading practice.

## Phase 1

- App Router + TypeScript + Tailwind CSS
- System dark mode via `next-themes`
- Landing page with paper-mode banner
- Client health check against `NEXT_PUBLIC_API_URL/health`

## Local run (without Docker)

```bash
npm install
npm run dev
```

Open http://localhost:3001
